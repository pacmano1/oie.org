---

The Eclipse Foundation creation review is complete. Open Integration Engine has entered incubation, and the project's formal name is now Eclipse Open Integration Engine. We will still call it OIE in most places.

This is the step the [June application](/news/eclipse-foundation-application/) was working toward. Community review and creation review both happened in the open, and the project is now hosted by the Foundation.

The project name and its marks are now held by the Eclipse Foundation rather than by any individual or company. No single vendor can take the name, change the license, or put OIE behind a paywall, because no single vendor owns it. Development runs under the Eclipse Development Process, with the IP review and provenance practices that come with it.

Incubation is the starting phase for every new Eclipse project. It is not a probation. A project in incubation is working through the Foundation's processes and IP review, and a later graduation review moves it to mature status. You will see the incubation designation on this site and alongside downloads, because we would rather name the phase than let the Eclipse name suggest a status the project has not reached.

Nothing about the day to day changes. The code stays open under the same license, the plugins stay free, and the community keeps directing the work in the same repositories with the same issue tracker and the same Discord. If you are running OIE in production today, there is nothing here you need to act on.

Groundwork for an Eclipse Working Group continues, separately from project creation. That is where organizations depending on OIE can shape its roadmap, fund its growth, and help promote it across the industry.

To get involved, or to follow along, reach out on Discord or at info@openintegrationengine.org.
